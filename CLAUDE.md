# Pax Futura

LLM-simulated grand-strategy sandbox (rewrite of `~/dev/games/open-historia`) with **loom-style branching timelines**: turns form a navigable tree; regenerating a turn creates a sibling node; advisor/diplomacy conversations are message-level trees scoped per turn node via head pointers, canonicalized by copy-on-turn-execution.

Full architecture & build plan: `~/.claude/plans/temporal-hugging-hummingbird.md`. Feature roadmap: `ROADMAP.md`.

- `pnpm dev` — server (tsx, :8787) + client (Vite, :5173) together

## Architecture (dependency direction is enforced by dependency-cruiser)

`domain ← providers ← engine ← server`; `domain ← client`. Client talks REST + one SSE channel only.

- `packages/domain` — Zod SSOT: world/turn/impacts (+ pure `applyImpacts`), facts, conversations, API/SSE contracts, Theme schema. Deps: zod + ulid only. LLM JSON schemas derive via `z.toJSONSchema` (`llm/jsonSchema.ts`).
- `packages/providers` — `LlmClient` interface + `FakeLlmClient` (deterministic tests). Real adapters: Anthropic/OpenAI-compat/Ollama.
- `packages/engine` — `SavePort` persistence interface (`ports.ts`), turn orchestrator, loom ops. No better-sqlite3 here.
- `packages/server` — Hono app, SQLite (better-sqlite3, WAL; one `app.sqlite` + one save DB per game in `saves/`), migrations via `PRAGMA user_version`, content-addressed gzip blob store for world snapshots, SSE hub w/ replay ring, range-aware `/assets` serving for PMTiles.
- `packages/client` — React 19 + Vite, Zustand stores (`loom/world/ui/session`), CSS Modules with **only `var(--pf-*)` tokens** (stylelint bans raw colors outside `src/theme/`), MapLibre v5 (**not v6** — react-map-gl 8.1 incompatible) + PMTiles.

- Presets (`client/src/theme/presets/*.json`): command-deck (glass + globe), seraphim (chamfer + hazard), parchment (atlas: paper, ripples, compass, IM Fell), daylight (frosted editorial), phosphor (CRT). Fonts are self-hosted via `@fontsource*` imports in `app/main.tsx` (faces only download when used).
- `applyTheme` derives material tokens (`--pf-panel-bg|bg-solid|inset|filter`, `--pf-accent-wash|line`, `--pf-glow-accent`, `--pf-text-glow`, `--pf-heading-*`, `--pf-cut`, `--pf-display-adjust`, …) and mirrors structure as `data-pf-corners|ornament|texture|glow` on `<html>`; `theme/skins.css` keys global hook classes on them: `pfPanel` (material + ornament via ::before/::after — host must be positioned; don't set background/box-shadow on it), `pfTitle`, `pfKicker`, `pfChamfer`, `pfRule`+`pfFleuron`, `pfGlowText`. - **Map** (`features/map/MapStage.tsx` + `lib/map/*`): base style = sea + procedural canvas patterns (`lib/map/patterns.ts`, registered on `styleimagemissing`, names carry the theme id) + graticule; projection/sky are react-map-gl props. Layers are ALL rendered unconditionally (visibility toggled) so creation order = render order survives style reloads. Marker detail follows zoom tiers (far/mid/near).

The dock publishes `--pf-dock-h`. Chrome over the map marks itself `data-occludes="top|bottom|left|right"`; `mapController` flies/fits to the centre of the visible area. ## Key invariants

- Turn execution: insert `generating` node + copy conversation head-pointers parent→child (that copy IS the canonical conversation) → stream LLM → validate (Zod) → `applyImpacts` → single transaction persist → activate. Cancel deletes the node; failure keeps it (`failed`) for retry. Regenerate = re-execute the node's frozen `input_json` against the same parent. A `max_tokens` stop is rejected BEFORE parsing (salvage can recover a valid-looking prefix — typically one bare headline) → corrective "be more compact" retry → actionable TurnFailedError if both truncate; all-headline turns (every description empty) are a validation error → retry (simulation-contract v2 demands 1-3 sentence descriptions).
- Polity data is ONE map keyed by canonical code (no parallel maps like the reference). `tags: []` clears, `null` = unchanged.
- Map: polity codes are GADM GID_0 (`FRA`, `DEU`, `GBR`), regions GID_1. Fills = `match` expressions built from theme-envelope palette (`client/src/theme/palette.ts`); explicit scenario colors keep hue, chroma clamps to theme. Country-level `regionOwnership` entries (3-letter keys) overlay polity self-colors — any GADM country is claimable (terra incognita), `toCode: null` clears ownership. The id vocabulary is vendored in `domain/src/world/regionCatalogData.ts` (generated from open-historia `regions-seed.geojson`); `validateTurnResult` rejects invented region ids.
- Map archives are symlinks in `assets/` → open-historia's `public/assets` (gitignored; 160MB not vendored).
